# UI reference patterns

These references inform interaction patterns only; the app keeps its own visual direction and scope.

## Monefy

Monefy uses prominent separate income and expense actions, then amount and category selection; the saved entry appears in the list and updates the category chart. This supports a fast, action-first flow. The personal app should keep the quick-entry path short and use the app's fixed data model.

Source: [Monefy Help Center](https://www.monefy.com/help-center).

## Money Manager by Realbyte

Money Manager offers bookmarked frequent entries and calendar/weekly/monthly summaries. A repeat-entry shortcut can reduce typing for recurring purchases, while a simple month summary gives a useful home-screen anchor.

Source: [Money Manager Home tab](https://help.realbyteapps.com/hc/en-us/articles/360046150874-Home-tab).

## Wallet by BudgetBakers

Wallet combines manual entry with configurable dashboard charts. This is useful reference for optional data summaries, but this app's first version should keep the dashboard focused on monthly income, expense, and balance.

Source: [Wallet Getting Started](https://support.budgetbakers.com/hc/en-us/articles/7151352625938-Getting-Started-with-Wallet).

## Candidate direction

Use a compact monthly overview, clear income/expense actions, recent records, and a single fast-entry surface with amount and common categories. Keep budgets, bank connections, and chart customization out of v1.
